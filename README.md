
# Lista de Compras

Aplicação para montar uma lista de compras dinâmica, com registro de data e horário de cada item.

## 🏷️ Sobre

Projeto desenvolvido durante os estudos de construção de páginas dinâmicas com JavaScript.

O objetivo é praticar manipulação do DOM, eventos e módulos JavaScript em uma aplicação web simples.

O usuário pode:

- adicionar itens à lista de compras;
- ver a data e o horário em que cada item foi adicionado;
- marcar um item como comprado através de um checkbox;
- visualizar uma mensagem quando a lista está vazia.

## 🧠 Conceitos praticados

- JavaScript;
- funções;
- manipulação do DOM;
- eventos;
- módulos ES (import/export);
- API `Date` e formatação de datas com `Intl`.
